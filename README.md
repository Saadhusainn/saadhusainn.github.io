# Sijjeen - Book Collage Maker

A web-based application for creating beautiful book collages with highlighting capabilities. Perfect for students, researchers, and book enthusiasts who want to create visual summaries of their reading materials.

![Sijjeen Collage Maker](https://via.placeholder.com/800x400/6c63ff/ffffff?text=Sijjeen+Book+Collage+Maker)

## 🌟 Features

### 📚 Book Management
- Browse and search through a collection of books
- Support for single books and multi-volume sets
- Upload your own PDF files
- Request books you can't find

### 🎨 Collage Creation
- Create collages with 2-5 pages
- Select specific page numbers
- Add custom watermarks with adjustable opacity
- Preview collage before downloading

### ✏️ Advanced Editor
- **Dedicated editor page** for precise highlighting
- **Multiple highlight colors** (yellow, red, cyan, green, blue, pink, purple, orange)
- **Zoom controls** (buttons + pinch-to-zoom on mobile)
- **Pan tool** for smooth navigation
- **Grid overlay** for alignment
- **Undo/Redo** functionality
- **Mobile-optimized** interface

### 📱 Platform Support
- Fully responsive design
- Touch-friendly controls for mobile
- Desktop-optimized toolbar
- Cross-browser compatibility
